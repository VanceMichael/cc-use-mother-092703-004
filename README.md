# 城市文旅活动容量与消费结算

统一管理节假日文旅活动容量、客流核销、演出收入和商圈结算。

## 参与方与事实

主要参与方包括文旅协调人员、景区与场馆负责人、演出主办方、商户、游客。领域资料记录以下已经确认的事实：

- 中秋假期北京接待游客878.3万人次、旅游总花费115.4亿元
- 假期举办308台951场营业性演出
- 运河艺术周、主题市集和京郊活动共同形成多场景消费

## 业务约束

- 容量上限
- 场次许可
- 核销去重
- 区域封闭
- 商户分账
- 统计关账

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/tourism_context.py` 负责读取和校验这些资料。
